Text after new lines creates the object instance and define what the thing being saved is. Then the text after tabs determine what variables to load in. And the a space after that is the value to be loaded.

The value is everything after that first space until the end of the line. So it can have spaces in it, and nothing needs to be escaped or turned into underscores.
The "#" comments below are only for this document. They are not part of the save file.
Lines that aren't recognised are skipped when loading. Values that can't be read are skipped too (the object is still made with what it can use).
Numbers are written as they are, without padding. The biggest account number or reference number is 99999999.
Money and amounts are floats but only two digits are saved.

DATABASE						# Must only be done once
	LastAccountID -1			# Kept so ids that belonged to deleted accounts aren't used again
	LastTransactionID -1		

ACCOUNT
	AccountNumber 0
	Name John Smith				# Can't be empty. Anything else goes, spaces included
	PhoneNumber 09171234567		# Can be empty
	PIN 0123					# Always PIN_LENGTH digits so it can start with a zero. Can be empty
	Money 1500.50
	
ACCOUNT
	AccountNumber 1
	Name Jane Doe
	PhoneNumber 
	PIN 4444
	Money 0.00
	
TRANSACTION
	ReferenceNumber 0
	Type TRANSFER				# TRANSFER, CASH_IN, CASH_OUT, BILL_PAYMENT or LOAD_PURCHASE
	From 0						# Account number so that the transaction can be loaded before the account. -1 if there is none (e.g. a cash in)
	To 1
	Amount 500.00

The save is written to e_peso.txt.tmp first and then replaces e_peso.txt, so a crash while saving doesn't corrupt the old save.
A save without any accounts counts as no save and the default account is made.
